# Тест-план fakestore-qa

## Область тестирования
Проект проверяет приложение Fake Store: витрину на React, которая использует
`fakestoreapi.com`. Покрытие включает слой REST API и три ключевых пользовательских
сценария в браузерном UI.

## Вне области тестирования
- Тестирование производительности и нагрузки
- Тестирование доступности
- Тестирование мобильной верстки за пределами базовой адаптивности

## Подход

| Уровень | Инструмент | Тип |
|---|---|---|
| REST API | behave (BDD) | Автоматизированный |
| Браузерный UI | Playwright + pytest | Автоматизированный |
| UI-сценарии | Ручные чек-листы | Ручной |

## Тестовые данные
API-проверки используют живые ответы Fake Store и проверяют контракт данных без
жесткой привязки к названиям или ценам товаров. Учетные данные используют
публичную тестовую учетную запись Fake Store: `mor_2314` / `83r5^_`.

## Критерии входа
- Витрина доступна по адресу `http://localhost:3000`
- `fakestoreapi.com` отвечает

## Критерии выхода
- Все автоматизированные тесты проходят
- Результаты Allure сформированы для наборов API- и UI-тестов

## Риски
- Проект зависит от публичного стороннего API, поэтому нестабильность внешнего
  сервиса может вызывать сбои, не связанные с самим приложением.
- UI-селекторы зависят от атрибутов `data-testid` в React-витрине.
