# Ручные тест-кейсы

## TC-01: Просмотр товаров

**Предусловие:** витрина открыта по адресу `http://localhost:3000`

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Открыть главную страницу | Отображается сетка товаров с несколькими карточками |
| 2 | Прокрутить каталог | Карточки товаров остаются видимыми и корректно стилизованными |
| 3 | Нажать `View` на любой карточке товара | Открывается страница с деталями товара |
| 4 | Проверить наличие названия, цены и описания | Все детали отображаются |
| 5 | Нажать кнопку «Назад» в браузере | Снова открывается сетка товаров |

## TC-02: Добавление в корзину

**Предусловие:** витрина открыта, пользователь находится на главной странице

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Зафиксировать счетчик корзины | Счетчик корзины отображается |
| 2 | Нажать `Add to Cart` для любого товара | Счетчик корзины увеличивается на 1 |
| 3 | Добавить еще один товар | Счетчик корзины снова увеличивается на 1 |

## TC-03: Вход в систему

**Предусловие:** витрина открыта

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Нажать `Login` в шапке | Отображается форма входа |
| 2 | Ввести имя пользователя `mor_2314` и пароль `83r5^_` | Поля принимают введенные данные |
| 3 | Отправить форму | Появляется сообщение об успехе, кнопка выхода отображается |
| 4 | Нажать `Logout` | Приложение возвращается в состояние без авторизации |
| 5 | Отправить неверные учетные данные | Появляется сообщение об ошибке |
